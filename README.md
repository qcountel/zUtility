# zUtility ⚔️

Стильная, оптимизированная и функциональная утилита для **Minecraft Pocket Edition v1.1.5 (Windows)**, разработанная на языке **Go** с использованием библиотеки **Fyne**.

Интерфейс утилиты выполнен в уникальном премиальном стиле **Dark Brutalist** — строгие формы с нулевым радиусом скругления (`CornerRadius = 0`), моноширинные шрифты, акцент на читаемость и кастомные цветовые палитры.

---

## 🎨 Особенности интерфейса (Dark Brutalist)

*   **Акцентные палитры**: Возможность выбора одного из 7 цветов оформления прямо в настройках (**Red, Blue, Green, Violet, Amber, Cyan, Pink**) с мгновенной перерисовкой всей темы приложения.
*   **Идеальное выравнивание**: Все переключатели модулей (`M3Toggle`) выровнены по правому краю карточек, образуя аккуратную и интуитивно понятную панель управления.
*   **Высокая производительность**: Плавная анимация переключения вкладок на базе аппаратного API `fyne.Animation` со стабильной частотой 60FPS+ без провисаний интерфейса.

## 📦 Основные разделы утилиты

### 1. MODULES (Модули)
Все игровые хаки и улучшения разделены на 4 логические категории для быстрого поиска:

*   **GAMEPLAY**:
    *   `AutoSprint` — постоянный автоматический бег.
    *   `ItemUseDelay` — устранение задержки использования предметов после совершения атаки.
    *   `TimeChanger` — удобное управление и фиксация внутриигрового времени суток.
    *   `OffVsync` — принудительное отключение VSync для повышения FPS и отзывчивости игры.
*   **VISUAL**:
    *   `Zoom` — плавное приближение с возможностью бинда на клавиатуру или геймпад.
    *   `NoHurtCam` — отключение раздражающей тряски камеры при получении урона.
    *   `NoCamReset` — предотвращение сброса направления взгляда игрока при телепортации.
    *   `NoDynamicFov` — отключение динамического изменения поля зрения (FOV) во время бега или эффектов скорости.
    *   `NoParticle` — полное отключение частиц для чистоты картинки и буста производительности.
*   **CONTROLLER** (Настройки ввода):
    *   `ControllerSensitivity` — разблокировка чувствительности стика контроллера выше стандартного лимита игры (всегда активный модуль со светящимся индикатором).
    *   `InstantHotbar` `[NEW]` — мгновенное переключение слотов хотбара на геймпаде. Опрашивает геймпад на частоте **120 Гц** через низкоуровневую библиотеку `winmm.dll`, эмулируя скролл мыши с нулевой задержкой и встроенной системой защиты от ложных нажатий (debounce 180 мс).

### 2. CLICKER (Автокликер)
Продвинутый инструмент для авто-клик-атак:
*   Раздельная настройка CPS (кликов в секунду) для левой и правой кнопок мыши.
*   Удобный бинд клавиши активации.
*   **Джиттер (Микро-рандомизация)** `[NEW]`: При включении этой функции задержки между кликами рандомизируются в пределах **22%**, имитируя клик реального человека. Это гарантирует надежный обход современных серверных античитов без риска блокировки.

### 3. PACKS (Менеджер ресурспаков)
Полноценный встроенный хаб для управления текстурами с ленивым кэшированием (переключение вкладок происходит за 0 мс):
*   **ONLINE**: Каталог доступных для загрузки ресурспаков.
*   **INSTALLED**: Локальный менеджер установленных текстур.
    *   Автоматическое сканирование папки ресурспаков Minecraft (включая клонированные инстансы).
    *   Парсинг файлов `manifest.json` для отображения реальных имен и описаний текстурпаков.
    *   Загрузка и отображение иконок `pack_icon.png` с высококачественным сглаживанием.
    *   Быстрый экспорт в `.mcpack` (в виде сжатого zip-архива) с автоматической валидацией расширения.
    *   Возможность удаления установленных паков прямо из интерфейса.

### 4. SETTINGS (Настройки)
*   **Выбор цвета акцента** (7 бруталистских оттенков).
*   **Переключение языка** интерфейса (RU / EN).
*   **Управление конфигурацией**: Быстрый сброс настроек, ручной экспорт и импорт в формат JSON.
*   Файл конфигурации автоматически сохраняется по пути: `%USERPROFILE%\.zutil\config.json`.

## ⚙️ Системные функции и оптимизации
*   **Single Instance Mutex**: Защита от случайного запуска нескольких копий программы одновременно.
*   **System Tray**: Сворачивание утилиты в системный трей для работы в фоновом режиме.
*   **Direct Memory Write**: Интеграция с памятью процесса `Minecraft.Windows.exe` через динамический поиск указателей и оффсетов.
*   **Оптимальный High-DPI**: Интерфейс идеально масштабируется на любых мониторах, шрифты имеют четкий отрендеренный вид без лесенок и размытия.

## 🚀 Требования и Сборка

### Требования
*   ОС: **Windows 10 / 11** (x64).
*   Игра: **Minecraft Pocket Edition v1.1.5** (процесс должен называться `Minecraft.Windows.exe`).
*   Среда разработки: **Go v1.20+**, установленный **GCC** (для CGO компиляции библиотеки Fyne и Win32 API).

### Компиляция проекта
Для компиляции приложения в один исполняемый файл без консольного окна в фоне, выполните следующую команду в корневой папке проекта:

```bash
go build -ldflags="-H windowsgui" -o zUtility.exe main.go
```

Или воспользуйтесь готовым скриптом сборки:
```bash
.\build.bat
```
