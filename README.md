# zUtility

Утилита для **Minecraft Pocket Edition 1.1.5** на Windows.
GUI: **Fyne**.

## Актуальные модули

- `AutoSprint` — постоянный спринт.
- `NoHurtCam` — отключает тряску камеры при уроне.
- `NoCamReset` — отключает сброс камеры при телепорте.
- `NoDynamicFov` — убирает динамическое изменение FOV.
- `NoParticle` — отключает частицы.
- `NoFire` — очищает флаг `ON_FIRE` (может нагружать CPU).
- `ControllerSensitivity` — чувствительность контроллера выше лимита игры.
- `Zoom` — зум с биндом клавиши/кнопки.
- `TimeChanger` — изменение и фиксация внутриигрового времени.
- `ItemUseDelay` — убирает задержку использования предметов после атаки.

## Что есть в утилите

- Переключение языка интерфейса: `RU / EN`.
- Сохранение настроек в `%USERPROFILE%\\.zutil\\config.json`.
- Экспорт/импорт конфигурации (`JSON`).
- Глобальная горячая клавиша показа/скрытия окна.
- Сворачивание в системный трей.
- Защита от двойного запуска (single instance).
- Поддержка биндов с клавиатуры и геймпада для `Zoom`.

## Требования

- Windows 10 / 11.
- Запущенный процесс игры: `Minecraft.Windows.exe`.

## Примечания

- Названия модулей в UI — на английском (`PascalCase`).
- Описания модулей и системные тексты зависят от выбранного языка (`RU/EN`).
